# 哈威求生指北

**HITWH Survival Compass**

一本由哈威学生共同编写的非官方大学指南。

> 方向仅供参考，人生请自行探索。

![打开一本书，通向海边的远方](assets/handbook-cover.webp)

[开始阅读](docs/start.md) · [参与共建](CONTRIBUTING.md) · [GitHub 仓库](https://github.com/zuquanzhi/hitwh-survival-compass)

## 从这里出发

不论你是刚来到哈威，还是正在思考下一步，这里希望帮你找到值得继续探索的方向。手册正在建设中，以下页面列出了我们希望共同回答的问题；校园事实和个人经验会在核实后逐步补充。

### 初到与生活

从[初识哈威](docs/arrival.md)、[校园生活](docs/life.md)和[身心健康与支持](docs/wellbeing.md)开始，了解未来可以在这里找到哪些信息。

### 学习与探索

在[学习与成长](docs/study.md)、[专业探索](docs/majors.md)、[科研与实践](docs/research.md)及[工具与信息](docs/tools.md)中，寻找不同的学习方法与视角。

### 未来与选择

[发展与选择](docs/future.md)关注深造、就业与其他可能的道路。每个人的条件和目标不同，经验可以参考，选择由你决定。

## 我们相信

**谦虚、真诚、严谨、求真。** 承认经验的边界，真诚分享和交流；认真核实信息，面对错误及时修正。我们欢迎不同的经历与观点，也愿意随着新证据不断更新。

## 一起把它写下去

你不需要是专家，也不需要一次写完一整章。一条经过核实的信息、一段注明背景的经历，或一次对过时内容的修正，都能帮助后来者。

从[社区与贡献](docs/community.md)了解项目，再按照[贡献指南](CONTRIBUTING.md)通过 GitHub Pull Request 参与。我们欢迎不同年级、专业和发展方向的同学，让不同经验并存。

本项目由学生自发维护，与学校官方无关，不以盈利为目的。涉及政策、资格、费用与期限时，请以最新官方信息为准。
