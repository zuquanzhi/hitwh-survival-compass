# 哈威求生指北

**HITWH Survival Compass**

一本由哈威学生共同编写的非官方大学指南。

> 方向仅供参考，人生请自行探索。

[开始阅读](docs/start.md) · [参与共建](CONTRIBUTING.md) · [GitHub 仓库](https://github.com/zuquanzhi/hitwh-survival-compass)

## 关于项目

这里汇集不同年级、专业和发展方向的同学分享的经验。我们尊重不同选择，鼓励独立判断，也欢迎不同观点并存。内容力求真实、准确、及时；具体政策请以相关官方信息为准。

项目由学生自发维护，与学校官方无关，以开放共享为目的，不以盈利为目的。目前处于搭建阶段，章节内容等待社区补充。

## 浏览手册

- [初到与生活](docs/arrival.md)：初识校园、日常生活与支持资源。
- [学习与探索](docs/study.md)：学习方法、专业、科研与工具。
- [发展与选择](docs/future.md)：不同路径上的探索与经验。
- [社区与贡献](docs/community.md)：了解如何加入共建。

目前各章节以写作方向为主，校园信息等待核实和补充。
