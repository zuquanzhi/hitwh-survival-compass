# 开始阅读

欢迎来到哈威求生指北。这是一本由学生共建的非官方手册，目前正在搭建中。章节中的问题和主题是写作方向，尚不代表已核实的校园信息。

- 初到校园，可以从[初识哈威](arrival.md)和[校园生活](life.md)开始。
- 想了解学习方法与资源，可阅读[学习与成长](study.md)和[工具与信息](tools.md)。
- 正在思考专业、科研或毕业去向，可以查看[专业探索](majors.md)、[科研与实践](research.md)及[发展与选择](future.md)。
- 愿意分享经历？请阅读[参与共建](../CONTRIBUTING.md)。

个人经验有适用背景与时间限制。涉及政策、资格、费用或截止日期，请以最新官方信息为准。
