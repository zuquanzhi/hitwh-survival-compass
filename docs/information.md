# 查找与判断信息

大学里的信息可能来自正式通知、他人的经验和群聊。它们各有用途，但适用范围和可靠程度不同。遇到影响个人决定的事情，可以按以下顺序核对。

## 从原始信息开始

1. 找到发布规则或通知的机构及原始页面，确认标题、发布日期和适用对象。
2. 查找是否有更新、补充通知或适用于自己年级和专业的说明。
3. 记录网页链接与查询日期；遇到权限限制或表述不清时，向负责该事项的单位核实。
4. 涉及期限、资格、费用或个人权益时，以办理单位当前答复及正式文件为准。

群聊截图、转述和旧文章可以提供线索，但不宜作为唯一依据。搜索到旧信息时，留意它是否有明确的年份和适用范围。

## 阅读个人经验

判断经验是否适合自己，可以先看作者的年级、专业、时间、目标和具体处境。同一条建议在不同阶段可能带来不同结果；对有争议的问题，多看几种经历，再结合自己的情况判断。

## 发现内容过时怎么办

若你发现手册中的描述已变化，可以通过 [Pull Request](../CONTRIBUTING.md) 提交修正，附上可公开访问的来源和核实日期。无法确认新信息时，也可以在 PR 中说明问题，避免用猜测替换原文。请勿上传个人隐私、受限通知或未经许可的材料。
